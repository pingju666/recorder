Media Recorder 
 
======================================== 
          Media Recorder 
======================================== 
 
Usage: 
1. Double click recorder.exe to launch the program 
2. Grant camera and microphone permissions on first run 
 
System Requirements: 
- Windows 10 or higher 
 
Features: 
- Supports camera, screen, and window recording 
- Supports audio recording 
- Supports video playback 
- Supports encoder and metadata settings 
- Supports custom save path 
- Displays file names in media list 
- Shows screen as default video source on startup 
 
Version Info: 
- Qt 6.8.3 
- FFmpeg 7.1
